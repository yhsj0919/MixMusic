# MixMusic v2

基于插件的音乐播放器，当前处于重写与功能验证阶段。宿主提供统一页面与播放队列，插件提供数据和操作。

- 插件 ZIP 安装、更新、启停、卸载及日志。
- 多音源搜索，歌单、专辑、歌手、排行榜和 MV 详情。
- 歌手专辑按需分页，排行榜切换音源。
- 音质选择、播放队列、四种播放模式与集合惰性加载。
- 简单播放页、全局歌词及多目录本地播放。
- 定时停止：0–90 分钟倒计时、到时播完本曲或立即暂停、本曲结束后停止。
- 应用音量、静音、倍速、保留进度切换音质，以及带预设的 18 段均衡器。
- 音乐缓存：边播边写入、同音质跨启动复用、容量与清理设置及调试日志，见 [缓存说明](docs/music-cache.md)。
- 单曲及集合批量下载：动态解析链接、按需分页、分组管理、取消、可配置重试与日志，见 [下载说明](docs/download.md)。

MV 目前只展示信息、打印地址，不播放视频。本地收藏、历史、歌单持久化及完整本地音乐库尚未接入。

开发使用本地 Lemon 库；音源插件实现在独立仓库，不包含在本项目中。首批目标为 Android、Windows 和车机。

详见 [开发计划](docs/development-plan.md)、[功能规划](docs/new-version-features.md) 和 [集合详情与按需播放](docs/collection-playback.md)。

各功能的实测结果及未验证平台见 [功能与平台验收清单](docs/platform-validation.md)。

播放与下载的公共惰性队列见 [HyperQueue](docs/hyper-queue.md)。
