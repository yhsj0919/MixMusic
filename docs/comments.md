# 评论

首版入口为歌曲操作菜单“评论”，搜索、推荐、歌单等共用该菜单。插件不支持时不显示入口。

2026-10-20 新接口更新（插件 2.0.23）：最新、热门、明星空降均已接入并支持分页。三类各两页真实匿名读取无重复，宿主相关 11 项功能回归通过。以下首批限制为 2.0.22 的历史说明，已由本次更新取代；实际设备与用户实测待完成。

宿主使用 `MusicApi.songComments(song, category, page, size, cursor)`，参数在 Dart 中为命名参数；插件对应 `songComments(song, options)`。仅公开业务接口，平台参数转换、内部请求及字段映射留在插件。歌曲 ID、分类 ID 和分页游标保持不透明，不新增资源身份 type。

2026-10-20 分类归属修正（插件 2.0.24）：宿主不内置分类名称、数量、语义或默认值。首次请求 `category:null`，插件决定默认分类并在结果返回 `category`（当前 ID）、`categories:[{id,title}]`；切换和分页时原样传回 ID。分类 ID 可为数字、字符串或可序列化对象，不转成字符串。没有分类的插件可省略 categories / category，宿主直接展示列表且不补“默认 / 全部”分类。

不新增分类辅助公共接口，也不为查询分类另发请求。QQ 的具体分类和默认项仅存在于独立插件里；页面根据元数据展示，未知的新分类也不需要改宿主。12 项相关功能回归覆盖插件默认项、无分类、任意分类名称、对象 ID、重复选择及分页重置。音频评论不在本次修改范围。

- 最新、热门、明星空降：支持按需分页、加载更多、刷新和失败原页重试，三类使用同一页面与控制器。
- 明星空降使用插件明确的分类查询，不按评论身份字段猜测筛选。
- 续页游标对宿主保持不透明；插件内部保留评论序号、上次总数及总数版本，切换分类或刷新时一起重置。仅按插件返回的续载标记决定是否继续，不提前拉取全部评论。
- 展示：用户名称、正文、时间、点赞数量；点赞数量仅展示，未开放点击点赞。
- 当前不包含：回复列表、发布、点赞、删除、其他资源评论。确认接口后逐项补充，继续复用页面与状态逻辑，不给每种资源造一套页面。

控制器在页面 initState 创建并开始加载，不在 Obx 构建期间首次初始化有状态副作用的对象。

2026-10-20 验证：11 项相关宿主功能回归和独立插件离线测试通过；匿名真实读取最新评论两页无重叠、热门首批及字段类型通过。平台用户实测待完成，不视为 Android / 车机验收通过，也不做 UI 验证。
