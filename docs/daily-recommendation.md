# 每日推荐

2026-10-19 用户实测：当前 Windows 测试版本登录后的每日推荐加载正常，重启后仍可正常加载。Android/车机尚未确认；本次不等同于过期会话自动续期通过，下文未验证描述为此前历史记录。

2026-10-16：沿用 v1 的独立页面、平台 Tab 和 `recommendInfo(page, size)` 流程。

- 桌面侧栏、手机首页标题栏提供入口，只展示声明该接口且已启用的插件。
- 默认选择首页平台（支持该接口时），否则首个可用插件。首次只请求当前平台；切换保留各平台歌曲、页码与错误，不聚合请求。
- API 返回 `MusicCollection`，歌曲在边界解析为对象，保留原始动态 ID；分页优先使用插件的 `hasMore`、`total`，缺失时按页长判断。
- 复用 `CollectionController` 与现有歌曲详情列表：播放全部、加入播放列表、下载全部、单曲操作、滚动加载与失败重试。队列继续使用 HyperQueue，离开页面不丢失后续分页。
- 手动刷新当前平台，从第一页重新获取；不定时刷新、不预拉全部。
- 宿主不判断登录、会员和站点条件。插件主动抛出业务异常，宿主展示原异常文本并记录插件日志，失败不推进页码，可重试。

独立插件仓库 QQ 2.0.3 在插件内部检查空 Cookie，并保留旧接口的分页结束与总数标记；该检查不代表 Cookie 有效性验证。插件实现与测试不进入宿主仓库。

63 项相关功能回归通过，涵盖每日推荐对象、分页、平台状态、异常透传、刷新，以及播放/下载集合续载。QQ 桥接的无 Cookie 异常和终页标记离线测试通过。实际登录后的推荐、Windows/Android/车机使用尚未验证，不做 UI 验证。
