## 开发约定

- 保留旧版代码组织、命名、页面视觉风格与布局习惯，使用新库重写实现。
- UI 使用 `lemon_ui`，缺少组件交给作者补，不在宿主另造组件。
- 路由只用 `go_router`，状态只用 `lemon_x`。
- 插件以 `lemon_js_extensions` 为基础，登录由插件负责；后期插件 UI 也统一到 `lemon_ui`。
- 宿主只定义评论等大类功能；插件内部的小类型、筛选项、分类名称和默认项由插件提供，不能把某个平台的分类固化进宿主。无分类直接展示，有自定义分类按插件元数据展示并原样传递 ID。
- 保持代码直接简洁，先验证成功路径。需要调整目录组织时先说明原因。
- JS 插件同样参照作者 v1 原始写法：按业务对象分组、请求参数与返回映射展开写清楚、使用直观的命名与少量辅助函数；保留简洁但不压成密集单行表达式。不为风格统一强行切换原有异步写法，不增加多余封装或防御性判断。平台源码和对应样本仍只在插件仓库维护。
- 页面可快速替换：页面仅负责展示、临时交互状态和调用简洁 API；播放、队列、歌词、定时、音效及后续缓存不依赖具体页面。共享弹窗交互与格式化独立存放，不通过导入某个播放页获取功能。
- 主线使用 Flutter stable，首批验证 Android、Windows 和车机。

## 3. 队列与系统媒体

均衡器预设已扩充为 16 组：平直、低音增强、人声、高音增强、流行、摇滚、古典、爵士、电子、舞曲、民谣、原声、柔和、明亮、低音减弱、高音减弱。均为自定义的 18 段 EQ 曲线，作为试听起点，不代表标准或专业校准，不包含环绕、混响等空间效果。

播放栏“播放设置”已接入应用音量（0–100%）、独立静音、0.5–2 倍速和播放中切换音质。状态保存在全局 PlayerController，首次初始化音频时应用已有设置；切歌不重置。系统临时压低音量以用户音量为基准，恢复时不跳回满音量。倍速同时传给歌词和系统媒体状态。

切换音质保持当前进度、播放/暂停状态、歌词及队列位置，原资源身份不变；向插件重新解析地址，并在 MPV 加载时应用起点。暂停状态下先保存新媒体和位置，继续播放时才解析；此时跳转也会更新待播放位置，不对旧文件执行 seek。

均衡器使用 MPV 原生 18 段 superequalizer，通过现成类型化接口接入，不修改音频库。提供启停、−12 至 +12 dB、平直/低音增强/人声/高音增强预设及自定义，滑块松手生效；关闭时保留频段设置，不覆盖其他效果槽位。配置暂不持久化；只作用于本机播放。Windows 原生接口与解码测试通过，Android 音效仍待实机确认，不做 UI 验证。

定时停止已按旧版主要逻辑接入：0–90 分钟滑块，松手启动或重设，0 分钟取消；可选择到时立即暂停或播完当前歌曲再停止，另提供“本曲结束后停止”。状态由全局 PlayerController 持有，播放栏计时按钮打开弹窗，关闭弹窗不影响计时。曲终等待优先于四种播放模式和集合续载，不清空歌曲、队列或退出应用。取消恢复正常播放流程；不持久化定时任务，应用销毁时释放计时器。本阶段只验证功能，Android 后台长时间计时仍待实机确认。

简单播放页已接入普通 `LyricView`，点击底部歌曲信息进入，展示封面、歌曲信息、歌词与现有播放控制。歌词独立获取，支持 LRC / Enhanced LRC、翻译合并、进度跟随和点击跳转；不使用 Canvas。作者确认只有 Canvas 版本存在性能问题，基础歌词无需先优化。插件自定义结构化逐字数据尚未统一协议，不在此处猜测转换。
