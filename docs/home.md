# 首页与完整列表

2026-10-22：手机首页快捷区提供“本地音乐 / 全部歌手 / 导入歌单”。快捷区放在推荐加载状态之外，未安装音源、推荐加载中或失败时仍可进入；本地音乐复用 `/local`，目录配置仍在设置“音乐目录”。桌面侧栏不变。

2026-10-16：新版保留旧版业务流程，只更换实现与扩展插件能力。

- 首页按当前默认插件同时发起 `songRec`、`playListRec`、`albumRec`、`mvRec` 中已声明的接口，分区独立显示和重试；不再点击“查看”才加载推荐。仅提供 `getHome` 的插件沿用该入口，正常推荐接口不额外重复调用 `getHome`。
- 首页默认平台以 SP 键 `homeSource` 保存。Windows 可在首页切换，Android 在设置选择；不聚合请求全部平台。切换或刷新后旧请求不得覆盖当前数据。
- 歌单、专辑、MV 的“查看”进入完整列表，展示平台 Tab、分类与按需分页。保留各平台已浏览的数据和分类；切换分类重置列表，不改插件原始分类参数。
- 排行榜是独立页面，平台 Tab 下直接展示分类标题和具体榜单；点击榜单进入详情，不经过中间分类页面。嵌套分组在当前页面展开，空分组不作为榜单请求。
- 歌单、专辑、榜单详情仅展示原平台资源，不放平台 Tab，不自动跨平台匹配；继续复用现有播放与下载功能。MV 保留详情和地址输出，暂不接视频播放。
- 外部身份始终为 `pluginId + 原始动态 id`，对象 ID、数字 ID 和字符串 ID 不相互转换。真实插件代码留在独立插件仓库。

布局直接参考 `.v1-backup`：桌面歌单/专辑 160×200、MV 270×200、新歌 160×204、间距 4；手机歌单/专辑 100×140、MV 178×100 图上标题、间距 12。使用现有 lemon_ui，不新增宿主组件或修改依赖。

播放条：桌面顶部细进度条，下方左侧封面与歌曲、中间播放控制和实际音质、右侧队列/下载/定时/音量/设置；手机使用紧凑行，模式、上一首和定时等保留在播放设置。进度拖动只预览，松手提交 seek。展开播放器保持现有功能。

验证仅做功能测试和静态检查，不做 UI 测试。真实插件完整列表、分类、榜单详情及 Windows/Android 实际使用待用户确认。
