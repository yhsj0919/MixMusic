# 独立歌词与匹配

2026-10-21：首版实现，真实插件与本地音乐设备体验待验证。

## 边界

- `LyricMatcher` 负责歌词获取与候选搜索，仅复用 `SongMatcher` 的规范化和评分，不依赖音频匹配服务。
- `MatchedLyric` 保留独立的歌词来源 `Song` 和完整返回数据，不把歌词来源塞进 `Song.matchedSong`。
- `PlayerController.lyric`、`lyricSource` 是全局数据，不依赖播放页；现有 `PlayerLyric` 继续负责解析、逐字、翻译和媒体标题同步。
- 开始播放时独立发起歌词请求，不等待音频初始化、地址解析或实际播放。歌词失败不改变音频播放状态，音频失败也不清除已取得的歌词。
- 歌词使用独立请求序号，切歌、重取或停止后旧结果不能覆盖当前歌词；临时音质变化和手动音频切源保留歌词，不取消同一首歌仍在进行的歌词请求。

## 获取规则

1. 始终调用原歌曲的 `lrc`，与当前音频是否匹配无关。
2. 原歌词 `lrc` 为空或失败，且启用歌词匹配时，按独立配置搜索歌词来源。
3. 当前复用 `searchMusic + lrc`：不要求 `playUrl`，不调用任何播放地址接口。
4. 每个来源搜索第一页20条，复用音源匹配的85分阈值和版本冲突规则；来源按设置顺序、候选按评分排序，最多尝试3条，错误隔离。
5. 无合格歌词时返回空结果，播放器显示暂无歌词，不硬选低分结果。

本地 API 当前返回空歌词，因此可以进入匹配；取得本地音频标签导致歌名或歌手变化时，会重新请求歌词并使旧请求失效。尚未新增本地内嵌/同名歌词文件读取能力。

## 入口与格式

- 设置 → 歌词匹配：独立开关（默认关闭）、来源选择、顺序，SP保存。与音源匹配开关/来源分开。
- 播放页：显示歌词实际来源，歌词图标打开当前歌曲的“歌词候选”列表，不直接重取歌词。列表展示来源、对应歌曲和评分，允许选择原歌曲歌词或手动切换候选；显式“重新搜索”放在弹窗内。候选查询复用本轮自动匹配结果，来源设置变化后清理旧候选。
- 自动匹配仍只尝试高分结果；手动列表保留低分候选供明确选择。切换歌词不重载音频，不改变播放来源、进度、暂停状态和原歌曲身份。空/失败候选保留当前歌词，并提示未切换；旧弹窗及过期请求不能覆盖新曲。
- `plugins.lyricMatcher.resolve(song)` 可供后续本地音乐或其他业务直接调用，不需要播放器。
- 当前可用正文沿用字符串 `lrc`；增强 LRC 可保留逐字时间。`translation`、`romanization` 及其他扩展字段原样保留。
- 不因插件返回新字段而丢弃它们，但尚未实现新的 QRC/YRC 等格式或逐字优先策略；不能把字段保留当成新格式已经能渲染。
- 当前不新增歌词缓存或持久化的匹配关联，也不修改音频缓存键。
