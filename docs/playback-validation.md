# 2026-10-23 Android 通知中断恢复

宿主初始化 LemonAudioConfig 时显式启用 `resumeAfterInterruption: true`。此前沿用库默认 false，通知造成暂时中断后会一直暂停。仍采用暂停策略，由 lemon_audio 在中断结束且中断前正在播放时恢复；不修改上游音频库或绕过音频焦点。待 Android 真机验证通知结束后的自动恢复、原本暂停时保持暂停及来电场景。本次未打包。

# 2026-10-23 加载失败后的重试与通知状态

用户在 Android 后台遇到 MpvEndFileError(-13, loading failed)，通知显示播放且进度前进，但没有声音。确认宿主此前只设置错误文字，未映射 LemonProcessingState.error；页面与通知继续调用底层 play，不重新加载已失败媒体。

修复：MPV 适配器锁定失败状态、停止上报 playing 并固定最后进度；页面与通知的播放操作在失败时重新进入歌曲加载，保留原身份、音质、匹配来源和进度，清除旧 URL 后重新解析。正常暂停继续和正常播完重播保持原路径。不修改 mpv_audio_kit 或 lemon_audio，不加入无限自动重试。
