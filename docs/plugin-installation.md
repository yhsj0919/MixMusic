## 安装方式

- 全局拖拽安装：在桌面端把插件文件拖入应用任意页面即可触发安装。
- 深度链接安装：通过应用链接或自定义协议打开插件安装页。
- 本地文件安装：由用户选择本地插件文件安装。

## 统一流程

拖拽、深度链接和本地文件选择只负责提供插件来源，之后统一进入同一套流程：

1. 读取插件。
2. 展示插件信息与权限。
3. 用户确认安装。
4. 安装或更新插件。

平台只处理入口差异，插件解析和安装逻辑不按平台重复实现。

## 平台范围

- Windows：支持应用内全局拖拽、本地文件和深度链接。
- Android：保留已有的外部打开和深度链接能力，并接入新版统一流程。
- 车机：根据系统提供的文件与链接能力接入，不作为首发硬性要求。
- 后续平台复用同一安装流程，只补平台入口。
