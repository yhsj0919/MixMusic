## 音质

设置页统一提供默认播放音质和默认下载音质，独立保存，初始均为标准 128；参考老版档位提供 128、320、1000、2000、3000。正常播放和下载直接使用预设，不必每次弹窗选择。控制器仍支持单次指定音质。

播放时优先从歌曲声明的音质中选择不高于预设的可用档位；未声明音质时将期望档位交给插件。播放页显示插件解析返回的实际音质，不用全局预设覆盖结果。播放页切换音质只影响本次播放，保留位置和暂停状态，不修改全局预设或队列快照；下一首及重新播放仍使用原有预设/明确入队音质。

下载独立使用下载预设，加入队列时确定，后续改预设不影响已入队任务；集合后续分页也沿用入队时的档位。不从歌曲上一次播放的音质推断下载音质。

待定：下载是否允许音质降级、后续音源匹配是否也用于下载。将来统一放在下载设置中配置，这次不新增宿主自动降级、跨音源下载逻辑或无效开关。播放的降级意图不代表下载策略已经确定。

## 目录与旧配置

本地音乐目录优先读 SP；SP 尚无记录时读取当前 v2 的 `music_directories.json` 并保存到 SP，不删除原文件。缓存的文件索引仍保留 JSON，只将开关和容量转到 SP；首次读取可接续现有 v2 缓存配置。不是 v1 数据迁移。

Android 下载目录继续使用 SAF 的持久读写授权。恢复已保存目录时检查系统授权及目录是否可读取；失效时保留设置并提示重新选择，不静默切换目录。更换下载目录不移动已有文件。Android 重启后的实际授权恢复、失效和重新选择仍待真机确认。

参考但暂不接入的老版配置：下载命名方式等，功能确定后再添加；旧版登录、会员匹配逻辑不迁入宿主。首页音源与同时播放设置现已接入。

收藏、历史、歌单、下载任务和续传记录不塞进 SP，本轮不新增持久化。定时停止也不跨重启恢复。

验证：111 项非 UI 功能测试、静态检查及 Android `compileDebugKotlin` 通过，包括控制器重建恢复、临时音质隔离、目录授权失效、本地目录迁移与缓存配置恢复。SP 使用模拟存储验证，不等于 Windows/Android 实际重启实测通过。
