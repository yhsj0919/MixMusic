# 新版页面风格

新版保留现有播放器的整体页面风格和布局习惯，大概率继续沿用当前视觉方向，主要替换或调整 UI 组件。

- 页面实现重写，统一使用 `lemon_ui`。
- 后期由作者将 `lemon_ui` 扩展到插件 UI，使宿主和插件共用组件体系与视觉风格，形成统一的整体项目；该扩展属于后续规划。
- 旧页面保存在 `.v1-backup`，作为页面布局、配色、信息组织和交互的参考。
- 手机与桌面因技术不同产生的不一致可以统一，但不主动改成另一套视觉风格。
- 基础验证阶段的空白页面只是工程起点，不代表新版最终设计。

## 代码组织

布局骨架：手机纵向排列；电脑采用侧栏与页面的水平布局，并保留底部播放区；平板竖屏使用手机布局，横屏为播放器与手机页面并排。设备类型与方向分别判断，电脑缩小窗口也不自动视为手机。

桌面布局方向为外侧窄导航、可折叠次级侧栏和右侧主内容区；当前先保留系统窗口标题栏，不实施无边框窗口。桌面返回箭头放在页面外的公共顶部导航区，页面 AppBar 不重复显示返回；手机布局（含平板中的手机页面）在页面标题栏显示返回箭头，统一去掉“返回”文字。页面顶栏及扩展区固定，内容独立滚动。

新版保留现有代码组织风格，包括目录划分、文件命名和相关代码的放置习惯。开发功能前参考归档的 v1 结构，结合新库调整实现。

如果具体功能需要改变组织方式，先说明现有方式的问题、调整原因和建议改法，不主动引入另一套分层架构。
